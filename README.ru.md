Проект служит платформой для изучения троичных вычислений и моделирования основных архитектурных компонентов.

## Что такое сбалансированная троичная система?

**Сбалансированная троичная система** — это система счисления, использующая три цифры: **−1**, **0** и **+1** (обозначаются как `-`, `0`, `+`). В отличие от двоичной (основание 2) или обычной троичной (0, 1, 2), сбалансированная троичная система:

- Представляет отрицательные числа **естественным образом** — без отдельного знакового бита
- Имеет симметричный диапазон относительно нуля: *n*-тритное число охватывает значения от −(3ⁿ−1)/2 до +(3ⁿ−1)/2
- Использовалась в историческом **компьютере «Сетунь»** (МГУ, 1958)
- Обеспечивает элегантную арифметику: отрицание — это просто инверсия каждого трита (`-` ↔ `+`)

```
+--------------------------------------------------------------+
|                   Семейство процессоров T3                     |
+-------------------+------------------------------------------+
|     T3‑18          |              T3‑54                        |
|  18‑тритные слова  |        54‑тритные слова                   |
|  3 трайта/слово    |      9 трайтов/слово                      |
|  9 регистров РОН   |  9 регистров РОН (окна в планах)          |
|  Только In‑Order   |  In‑Order (VLIW/SIMD/Спекуляция в планах) |
|  Диапазон: ±193M   |  Диапазон: ±2.9×10²⁵                     |
+-------------------+------------------------------------------+
```

### Статус и зрелость проекта

| Статус | Компоненты | Примечания |
|---|---|---|
| **Stable** | TritTypes, Word18, In-Order процессор, базовый ассемблер, CLI | Основной функционал для T3-18 |
| **Beta** | FPU, компилятор T-lang, дизассемблер, Word54 | Работает, поддержка ISA v5 (Июль 2026) |
| **Experimental** | VLIW-ассемблер, GUI | Начальные прототипы, не полностью интегрированы |
| **Planned** | VLIW процессор, SIMD, Спекуляция, Оконные регистры, Прерывания | Описаны в архитектуре, еще не реализованы |

> Подробный статус каждого компонента: [SUPPORTED.md](SUPPORTED.md)

### Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **Единая ISA (v5)** | 38 базовых инструкций с ортогональной системой групп (GP/FPU/Special) |
| **Предикация** | Условное выполнение через флаги предикатов (регистр PR) |
| **Форматы вывода** | Троичный (`-0+`), 9‑ричный, 27‑ричный, двоичный |
| **Форматы ввода** | Текстовый, Ninary (`0n`), Tryx (`0y`), двоичный |
| **Учет задержек** | Подсчет тактов на основе таблиц задержек инструкций |
| **Аппаратные счётчики** | Счётчик тактов, инструкций, остановов через MMIO |
| **Отладчик CLI** | Интерактивный REPL с точками останова, трассировкой, дизассемблером |
| **Конвертер чисел** | Преобразование десятичных чисел в троичные/9‑ричные/27‑ричные и обратно |

## Быстрый старт

### Требования

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее

### Сборка

```bash
dotnet build T3Sharp.sln
```

### Запуск CLI симулятора

```bash
dotnet run --project src/T3Simulator.CLI/T3Simulator.CLI.csproj
```

### Конвертер чисел

```bash
dotnet run --project src/T3NumberConverter/T3NumberConverter.csproj all 42
dotnet run --project src/T3NumberConverter/T3NumberConverter.csproj d2t -100
dotnet run --project src/T3NumberConverter/T3NumberConverter.csproj t2d +-0
```

### Запуск тестов

```bash
dotnet test T3Sharp.sln
```

## Конфигурации процессора

### Типы слов

| Тип | Тритов | Трайтов | Диапазон | Внутреннее хранение (C#) |
|-----|--------|---------|----------|---------------------------|
| **T3‑18** | 18 | 3 | ±193 710 244 | `long` / `int` |
| **T3‑54** | 54 | 9 | ±2,9 × 10²⁵ | `BigInteger` / `Int128` |

### Регистровый файл (ISA v5)

В ISA v5 регистры разделены на три группы (**RegGroup**), что обеспечивает ортогональность команд.

#### 1. GP-регистры (General Purpose, без префикса)
| 0: RW | 1: RX | 2: RY | 3: RZ | 4: R0 | 5: R1 | 6: R2 | 7: R3 | 8: R4 |
|-------|-------|-------|-------|-------|-------|-------|-------|-------|
* **RZ (3)** и **R3 (7)** — теперь обычные callee-saved GP-регистры.
* **R1 (5)** — цель вызова (call target), **R2 (6)** — возвращаемое значение.

#### 2. FPU-регистры (префикс `F.`)
| F0 | F1 | F2 | F3 | F4 | FW | FX | FY | FZ |
|----|----|----|----|----|----|----|----|----|
Используются для операций с плавающей точкой.

#### 3. Special-регистры (префикс `S.`)
| FP | HP | SP | CD | PR | WD |
|----|----|----|----|----|----|
* **FP** — Frame Pointer (автоматически управляется CALL/RET)
* **HP** — Heap Pointer
* **SP** — Stack Pointer
* **CD** — Condition flag (результат CMP)
* **PR** — Predicate register (предикация)
* **WD** — Window Pointer

### Память

- **1М слов** физической памяти (1 048 576 слов)
- Пословная адресация; стек растёт вниз
- Аппаратные счётчики, отображаемые на MMIO в выделенной области сразу после физической памяти (например, с адреса `0x100000` для 1М слов)

## Система команд (ISA v5)

### Формат инструкции

Каждая инструкция занимает **1 слово (18 тритов)**:
`[ Pred(3) | RegGroup(1) | Fmt(1) | Opcode(4) | Args(9) ]`

- **Pred**: Предикат выполнения (0..2).
- **RegGroup**: Определяет целевой регистровый файл (-1: FPU, 0: GP, +1: Special).
- **Fmt**: Формат аргументов (-1: J, 0: R/S, +1: I).
- **Opcode**: Код операции (38 реализованных опкодов).
- **Args**: Операнды (регистры, immediate).

### Группы инструкций

| Группа | Мнемоники | Описание |
|--------|-----------|----------|
| **Арифметика** | `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `NEG` | Ортогонально работают в GP, FPU, Special |
| **Логика** | `AND`, `OR`, `XOR` | Потритовые операции (только GP) |
| **Сдвиги** | `SHL`, `SHR` | Сдвиги (только GP) |
| **Память** | `LD`, `ST`, `MOV`, `LIMM` | Доступ к памяти и константам |
| **Управление** | `JMP`, `JE`, `JNE`, `JL`, `JG`, `JM` | Переходы (без RegGroup) |
| **Подпрограммы** | `CALL`, `RET` | Вызовы с авто-FP (без RegGroup) |
| **Стек** | `PUSH`, `POP` | Манипуляции со стеком |
| **Ввод/вывод** | `IN`, `OUT` | Портовый ввод/вывод |
| **FPU** | `F.ADD`, `F.SUB`, `F.MUL`, `F.DIV`, `F.SQRT` | Операции с плавающей точкой |
| **Специальные** | `S.ADD`, `S.MOV` и др. | Операции над спец-регистрами |

### Пример программы на ассемблере (v5)

```asm
; Вычисление дискриминанта D = b^2 - 4ac
    MOV  R0, #1           ; a = 1
    MOV  R1, #-3          ; b = -3
    MOV  R2, #2           ; c = 2
    MUL  R3, R1, R1        ; D = b^2 = 9
    MUL  R4, R0, R2        ; E = a*c = 2
    ADD  R4, R4, R4        ; E = 4
    ADD  R4, R4, R4        ; E = 8
    SUB  R3, R3, R4        ; D = 1
    HALT

; Пример операции FPU с префиксом F.
    MOV  R0, #9
    ITOF F0, R0           ; F0 = 9.0
    F.SQRT F0, F0         ; F0 = sqrt(9) = 3.0
    HALT

; Пример работы со спец-регистрами
    S.ADD SP, SP, #-16    ; Выделение места на стеке
```

## Микроархитектуры

### Последовательный процессор (In‑Order)

- Одно АЛУ, последовательное выполнение
- Без конвейера, без спекуляции
- Предикация эмулируется (NOP при неудаче предиката)
- Поддерживается на T3-18 и T3-54

**Задержки инструкций (такты):**

| Инструкция | T3‑18 | T3‑54 |
|------------|-------|-------|
| ADD, SUB, MOV, LI, NEG, AND, OR, XOR, CMP, SHL, SHR | 1 | 1 |
| LOAD, STORE | 2 | 2 |
| MUL | 5 | 8 |
| DIV, MOD | 10 | 15 |
| CALL, RET, PUSH, POP | 2 | 2 |
| Переходы (не переход / переход) | 1 / 2 | 1 / 2 |
| FADD, FSUB | 5 | 5 |
| FMUL | 7 | 7 |
| FDIV | 15 | 15 |
| FSQRT | 20 | 20 |
