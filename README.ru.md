# T3Sharp — Исследовательский прототип троичного компьютера

[![.NET](https://img.shields.io/badge/.NET-8.0-purple.svg)](https://dotnet.microsoft.com/)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Ternary](https://img.shields.io/badge/троичный-сбалансированный-red.svg)](https://ru.wikipedia.org/wiki/Троичная_система_счисления)

**Экспериментальный исследовательский прототип** троичных процессоров на платформе .NET, реализующий архитектуру системы команд (ISA) на основе **сбалансированной троичной системы счисления**. Проект служит платформой для изучения троичных вычислений и моделирования основных архитектурных компонентов.

## Что такое сбалансированная троичная система?

**Сбалансированная троичная система** — это система счисления, использующая три цифры: **−1**, **0** и **+1** (обозначаются как `-`, `0`, `+`). В отличие от двоичной (основание 2) или обычной троичной (0, 1, 2), сбалансированная троичная система:

- Представляет отрицательные числа **естественным образом** — без отдельного знакового бита
- Имеет симметричный диапазон относительно нуля: *n*-тритное число охватывает значения от −(3ⁿ−1)/2 до +(3ⁿ−1)/2
- Использовалась в историческом **компьютере «Сетунь»** (МГУ, 1958)
- Обеспечивает элегантную арифметику: отрицание — это просто инверсия каждого трита (`-` ↔ `+`)

## Обзор архитектуры

```
+--------------------------------------------------------------+
|                   Семейство процессоров T3                     |
+-------------------+------------------------------------------+
|     T3‑18          |              T3‑54                        |
|  18‑тритные слова  |        54‑тритные слова                   |
|  3 трайта/слово    |      9 трайтов/слово                      |
|  9 регистров РОН   |  9 регистров РОН (окна в планах)          |
|  Только In‑Order   |  In‑Order (VLIW/SIMD/Спекуляция в планах) |
|  Диапазон: ±193M   |  Диапазон: ±2.9×10²⁵                     |
+-------------------+------------------------------------------+
```

### Статус и зрелость проекта

| Статус | Компоненты | Примечания |
|---|---|---|
| **Stable** | TritTypes, Word18, In-Order процессор, базовый ассемблер, CLI | Основной функционал для T3-18 |
| **Beta** | FPU, компилятор T-lang (прототип), дизассемблер, Word54 | Работает, возможны ошибки в редких случаях |
| **Experimental** | VLIW-ассемблер, GUI | Начальные прототипы, не полностью интегрированы |
| **Planned** | VLIW процессор, SIMD, Спекуляция, Оконные регистры, Прерывания | Описаны в архитектуре, еще не реализованы |

> Подробный статус каждого компонента: [SUPPORTED.md](SUPPORTED.md)

### Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| **Единая ISA** | 28 базовых инструкций + ввод/вывод + FPU (расширения VLIW в планах) |
| **Предикация** | Условное выполнение через флаги предикатов (регистр PR) |
| **Форматы вывода** | Троичный (`-0+`), 9‑ричный, 27‑ричный, двоичный |
| **Форматы ввода** | Текстовый, Ninary (`0n`), Tryx (`0y`), двоичный |
| **Учет задержек** | Подсчет тактов на основе таблиц задержек инструкций |
| **Аппаратные счётчики** | Счётчик тактов, инструкций, остановов через MMIO |
| **Отладчик CLI** | Интерактивный REPL с точками останова, трассировкой, дизассемблером |
| **Конвертер чисел** | Преобразование десятичных чисел в троичные/9‑ричные/27‑ричные и обратно |

## Конфигурации процессора

### Типы слов

| Тип | Тритов | Трайтов | Диапазон | Внутреннее хранение (C#) |
|-----|--------|---------|----------|---------------------------|
| **T3‑18** | 18 | 3 | ±193 710 244 | `long` / `int` |
| **T3‑54** | 54 | 9 | ±2,9 × 10²⁵ | `BigInteger` / `Int128` |

### Регистровый файл

Девять логических регистров общего назначения:

| 0: RW | 1: RX | 2: RY | 3: RZ | 4: R0 | 5: R1 | 6: R2 | 7: R3 | 8: R4 |
|-------|-------|-------|-------|-------|-------|-------|-------|-------|

**Специальные регистры:** `SP` (указатель стека), `PC` (счётчик команд), `Cond` (флаг условия, 1 трит), `PR` (предикатный регистр, 9/27 тритов).
**Регистры FPU:** `FW, FX, FY, FZ, F0, F1, F2, F3, F4` (индексы 0–8, совмещены с целочисленным регистровым файлом).

### Память

- **1М слов** физической памяти (1 048 576 слов)
- Пословная адресация; стек растёт вниз
- Аппаратные счётчики, отображаемые на MMIO в выделенной области сразу после физической памяти (например, с адреса `0x100000` для 1М слов)

## Система команд

### Группы инструкций

| Группа | Мнемоники | Описание |
|--------|-----------|----------|
| **Арифметика** | `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `NEG` | Сбалансированная троичная арифметика |
| **Логика** | `AND`, `OR`, `XOR` | Потритовые min, max, сумма по модулю 3 |
| **Сдвиги** | `SHL`, `SHR` | Умножение/деление на степени 3 |
| **Память** | `LOAD`, `STORE`, `LI`, `LIMM` | Доступ к памяти и непосредственные значения |
| **Управление** | `JMP`, `JE`, `JNE`, `JL`, `JG`, `JM` | Условные и безусловные переходы |
| **Подпрограммы** | `CALL`, `RET` | Вызовы с использованием стека |
| **Стек** | `PUSH`, `POP` | Манипуляции со стеком |
| **Ввод/вывод** | `IN`, `OUT`, `INI`, `OUTI` | Портовый ввод/вывод |
| **FPU** | `FADD`, `FSUB`, `FMUL`, `FDIV`, `FSQRT`, … | Операции с плавающей точкой (17 инструкций) |
| **VLIW** | `SPEK`, `COMMIT`, `VADD3`, … | Спекуляция, SIMD (только T3‑54) |

> Обратная совместимость: `TRITAND`/`TRITOR`/`TRITXOR` являются псевдонимами для `AND`/`OR`/`XOR`.

### Форматы инструкций

**R‑тип (регистр–регистр):**
```
[ opcode+pred (6) | op1 (3) | op2 (3) | op3 (3) | резерв/func (3) ]
```

**I‑тип (регистр–непосредственное значение):**
```
[ opcode+pred (6) | op1 (3) | op2 (3) | imm6 (6) ]
```

- `opcode+pred = базовый_опкод + индекс_предиката × 28`
- Диапазон `imm6`: −364 … +364 (смещение offset=364)

### Пример программы на ассемблере

```asm
; Вычисление дискриминанта D = b^2 - 4ac
    LI  A, 1           ; a = 1
    LI  B, -3          ; b = -3
    LI  C, 2           ; c = 2
    MUL D, B, B        ; D = b^2 = 9
    MUL E, A, C        ; E = a*c = 2
    ADD E, E, E        ; E = 4
    ADD E, E, E        ; E = 8
    SUB D, D, E        ; D = 1
    HALT

; Пример операции FPU
    LI  R0, 9
    ITOF FW, R0        ; FW = 9.0
    FSQRT FW, FW       ; FW = sqrt(9) = 3.0
    HALT
```

> **Полный справочник по системе команд:** [docs/t3-isa-reference.ru.md](docs/t3-isa-reference.ru.md)

## Микроархитектуры

### Последовательный процессор (In‑Order)

- Одно АЛУ, последовательное выполнение
- Без конвейера, без спекуляции
- Предикация эмулируется (NOP при неудаче предиката)
- Поддерживается на T3‑18 и T3‑54

**Задержки инструкций (такты):**

| Инструкция | T3‑18 | T3‑54 |
|------------|-------|-------|
| ADD, SUB, MOV, LI, NEG, AND, OR, XOR, CMP, SHL, SHR | 1 | 1 |
| LOAD, STORE | 2 | 2 |
| MUL | 5 | 8 |
| DIV, MOD | 10 | 15 |
| CALL, RET, PUSH, POP | 2 | 2 |
| Переходы (не переход / переход) | 1 / 2 | 1 / 2 |
| FADD, FSUB | 5 | 5 |
| FMUL | 7 | 7 |
| FDIV | 15 | 15 |
| FSQRT | 20 | 20 |

### VLIW процессор (В планах / Архитектурный дизайн)

*Примечание: Микроархитектура VLIW в настоящее время описана в спецификации, но НЕ реализована в ядре процессора.*

- **Цель дизайна**: Три идентичных АЛУ, работающих параллельно
- **Структура бандла**: Один бандл = три 18‑тритных слота в одном 54‑тритном слове
- **Планируемое обнаружение конфликтов**: конфликты записи в регистры, приоритет доступа к памяти, ограничения переходов
- **Планируемая спекуляция**: `SPEK`/`COMMIT`/`ROLLBACK` с теневым регистровым файлом
- **Планируемый SIMD**: векторные операции над тремя 18‑тритными подсловами (`VADD3`, `VMUL3`, `VDOT3` и др.)

```asm
; Синтаксис VLIW бандлов (поддерживается VLIW-ассемблером)
{ ADD R0, R1, R2 | MUL R3, R4, R5 | LOAD R6, R7 }
;  Слот 0           Слот 1           Слот 2
```

> **Полный справочник по архитектуре:** [docs/t3-architecture.ru.md](docs/t3-architecture.ru.md)

## Сопроцессор плавающей точки (FPU)

| Формат | Разрядность | Порядок | Мантисса (скрытый трит) | Смещение |
|--------|-------------|---------|--------------------------|----------|
| **tfloat** | 18 тритов | 6 тритов | 12 тритов | 182 |
| **tdouble** | 36 тритов | 8 тритов | 28 тритов | 3280 |

- 9 регистров данных FPU: **FW, FX, FY, FZ, F0–F4**
- Регистр состояния **FSR** доступен через порт `0x20`
- Исключения устанавливают флаги в FSR, но **не** генерируют прерываний
- Полный набор инструкций: `FADD, FSUB, FMUL, FDIV, FSQRT, FABS, FNEG, FCMP, FTOI, ITOF, FTOF, FLW, FSW, FMOV, FCLASS, FSWAP, FZERO`

## Кодировка T‑SCII

T‑SCII (Ternary Standard Code for Information Interchange) — 6‑тритная (трайтовая) кодировка:

| Диапазон | Содержимое |
|----------|------------|
| −364 … −1 | Греческий алфавит, псевдографика, стрелки, математические символы |
| **0 … 255** | **Совместимость с CP‑1251 (ASCII + кириллица + спецсимволы)** |
| 256 … 364 | Математические и технические символы |

### Примеры форматов вывода

| Формат | Пример (`'A'`) | Алфавит |
|--------|-----------------|---------|
| **Троичный** | `0 + - + + -` | `- 0 +` |
| **9‑ричный (Ninary)** | `0n1Y2` | `W X Y Z 0 1 2 3 4` (пары) |
| **27‑ричный (Tryx)** | `0y2B` | `N O P … A B C D` (тройки) |

## Конвертер чисел

Инструмент `T3NumberConverter` преобразует десятичные целые числа в сбалансированное троичное представление и обратно:

```
T3NumberConverter all 42
  Decimal : 42
  Ternary : +--+0
  9-ary   : 0n2Z0
  27-ary  : 0y7R

T3NumberConverter d2t -100
  -++0--
```

**Команды:** `d2t` (decimal→ternary), `t2d` (ternary→decimal), `d2n` (decimal→9-ary), `n2d` (9-ary→decimal), `d2y` (decimal→27-ary), `y2d` (27-ary→decimal), `all` (все форматы).

## Команды CLI

```
T3> help                    Показать доступные команды
T3> load program.asm        Загрузить программу на ассемблере
T3> run                     Выполнить до HALT
T3> run 100                 Выполнить до 100 инструкций
T3> step                    Выполнить одну инструкцию
T3> step 10                 Выполнить 10 инструкций
T3> dump registers ternary  Показать регистры в троичном формате
T3> dump registers nonary   Показать регистры в 9‑ричном формате
T3> dump registers 27ary    Показать регистры в 27‑ричном формате
T3> breakpoint 0x00000010   Установить точку останова
T3> breakpoint list         Список всех точек останова
T3> trace on                Включить буфер трассировки
T3> trace off               Выключить буфер трассировки
T3> disassemble             Показать дизассемблированную программу
T3> stack                   Показать содержимое стека
T3> memory 0x00000000 16    Показать 16 ячеек памяти
T3> exit                    Выйти из симулятора
```
