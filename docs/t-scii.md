# Полная таблица T‑SCII (27×27)

Каждая ячейка содержит символ, соответствующий комбинации старшей (строка) и младшей (столбец) 27‑ричной цифры.  
Управляющие символы показаны с помощью стандартных изображений (Control Pictures).  
Символы CP1251 (коды 0–255) расположены в строках `0`–`9` и частично `A`–`D`.  
Дополнительные символы (греческий, математика, псевдографика) занимают остальные позиции.

**Пояснения:**

- Символы CP1251 (0–255) занимают ячейки от `0 0` (NUL) до `9 D` (≠).  
- Управляющие символы представлены Control Pictures (␀ для NUL, ␁ для SOH, ␡ для DEL, ␠ для пробела).  
- Дополнительные символы (греческий алфавит, стрелки, математические знаки, псевдографика) заполняют остальные позиции согласно утверждённой таблице T‑SCII.  
- Последняя ячейка `D D` — заглушка (␀), обозначающая максимальный код.
