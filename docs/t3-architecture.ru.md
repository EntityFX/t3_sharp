# Архитектура процессора T3 — v2 (Исследовательский прототип)

## Типы слов

- **Word18**: 18 тритов, хранится как `int` (32 бита). Диапазон: ±193 710 244
- **Word54**: 54 трита, хранится как `Int128`. Диапазон: ±2.9×10²⁵
- **T3Float**: 18-тритный float (6 порядок + 12 мантисса)

## Регистровый файл (9 регистров)

| Имя | Трит | Phys | FPU |
|-----|------|------|-----|
| RW | -4 | 0 | FW |
| RX | -3 | 1 | FX |
| RY | -2 | 2 | FY |
| RZ | -1 | 3 | FZ |
| R0 | 0 | 4 | F0 |
| R1 | +1 | 5 | F1 |
| R2 | +2 | 6 | F2 |
| R3 | +3 | 7 | F3 |
| R4 | +4 | 8 | F4 |

Специальные регистры: SP, PC, Cond (1 трит), PR (9 тритов = 3×3 предикатных флага). 
*Примечание: оконный механизм регистров на данный момент является запланированной архитектурной особенностью и еще не интегрирован в модель исполнения.*

## Формат инструкции

```
[Pred (3)] [Opcode (6)] [Args (9)]
```

- R-тип: Args = `[Op1(3)] [Op2(3)] [Op3(3)]`
- I-тип: Args = `[Op1(3)] [Imm(6)]`
- J-тип: Args = `[Reg(3)] [000000]`

Регистры кодируются тритовым значением (-4..+4). Phys индекс = trit + 4.

## Память

- 1M слов (1 048 576) типа Word18/Word54
- Стек растёт вниз, SP = MemSize-1 при старте
- MMIO: CYCLE_LOW, CYCLE_HIGH, INST_COUNT, STALL_COUNT

## Модель исполнения (In-Order Прототип)

Текущая реализация представляет собой функциональный интерпретатор, а не потактовый конвейер.

1. Fetch: `word = Memory[PC]`
2. Decode: извлечение Pred, Opcode, Args
3. Predicate: пропуск, если условие предиката не выполнено (в настоящее время проходит стабилизацию для обеспечения согласованности между спецификацией и средой исполнения)
4. Execute: switch по Opcode
5. PC++ (если не переход)
