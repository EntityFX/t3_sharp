## 6. Инфраструктура тестирования

### Генерация отладочных дампов

При `CompilerDebugConfig.EnableDumps = true` каждый тест `TLangCompilerTests` генерирует:
- `.ast.txt` — дамп AST-дерева
- `.asm` — сгенерированный ассемблер
- `.bin.txt` — троичный бинарный код (строки из 18 тритов)
- `.trace.txt` — пошаговая трассировка выполнения (при падении)
- `.final.state.txt` — финальное состояние регистров и памяти
- `.crash.state.txt` — состояние при аварийном завершении

Дампы в `test_results/`.

### Запуск тестов

```bash
# Все тесты
dotnet test T3Sharp.sln

# Конкретный проект
dotnet test tests/T3Simulator.InOrder.Tests

# Фильтр по имени
dotnet test tests/T3Simulator.InOrder.Tests --filter "Compile_Array"
```
