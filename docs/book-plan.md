## Введение для читателя

Этот учебник предназначен для всех, кто интересуется троичными вычислениями: студентов, исследователей, разработчиков и энтузиастов. Материал излагается последовательно: от фундаментальной теории к практическому программированию.

Для изучения достаточно базовых знаний программирования. Знание языка C будет полезно, но не обязательно.

**Рекомендуемый порядок изучения:**
1. Прочитать Часть I и II для понимания троичной системы
2. Изучить Часть III (архитектура) для понимания устройства процессора
3. Познакомиться с ассемблером (Часть VI) и написать несколько простых программ
4. Изучить язык T-lang (Часть VII) и написать программы на нём
5. Использовать Часть X для запуска и отладки своих программ
