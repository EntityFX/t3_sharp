# Спецификация FPU для процессора T3 (18-тритное слово) — финальная версия

## 1. Введение

Данный документ описывает математический сопроцессор (FPU) для процессора T3. FPU оперирует числами с плавающей точкой в сбалансированной троичной системе и имеет собственный набор из 9 регистров данных (`FW...F4`).  
Для кодирования инструкций FPU выделен отдельный диапазон опкодов **92–108**, не пересекающийся с основным ISA (0–27) и I‑типами основных инструкций (65–81). Это гарантирует однозначное декодирование и не требует модификации существующего `enum Opcode`.

## 2. Форматы чисел

- **tfloat** (18 трит): 6 трит порядок + 12 трит мантисса (со скрытым тритом). bias = 182.
- **tdouble** (36 трит): 8 трит порядок + 28 трит мантисса. bias = 3280.
- Специальные значения: ноль, бесконечность, NaN, maybe‑NaN.
- Округление по умолчанию: к ближайшему, с правилом чётного младшего трита.

## 3. Регистры FPU

- **Регистры данных**: `FW, FX, FY, FZ, F0, F1, F2, F3, F4` (номера 0–8).
- В режиме tfloat каждый хранит 18 трит.
- В режиме tdouble используются пары: (FW,FX), (FY,FZ), (F0,F1), (F2,F3). `F4` в парах не участвует.
- **FSR** (регистр состояния) доступен через порт 0x20.

## 4. Коды операций FPU (диапазон 92–108)

| Код | Мнемоника | Тип | Описание |
|-----|-----------|-----|----------|
| 92  | `FADD`    | R   | `Fop1 = Fop2 + Fop3` |
| 93  | `FSUB`    | R   | `Fop1 = Fop2 - Fop3` |
| 94  | `FMUL`    | R   | `Fop1 = Fop2 * Fop3` |
| 95  | `FDIV`    | R   | `Fop1 = Fop2 / Fop3` |
| 96  | `FSQRT`   | R   | `Fop1 = sqrt(Fop2)` |
| 97  | `FABS`    | R   | `Fop1 = abs(Fop2)` |
| 98  | `FNEG`    | R   | `Fop1 = -Fop2` |
| 99  | `FCMP`    | R   | `Cond = sign(Fop1 - Fop2)` — флаг условия основного процессора |
| 100 | `FTOI`    | R   | `Rop1 = int(Fop2)` (округление к нулю). func выбирает разрядность целого: 0 – 18 трит, 1 – 54 трита |
| 101 | `ITOF`    | R   | `Fop1 = float(Rop2)` |
| 102 | `FTOF`    | R   | Преобразование tfloat ↔ tdouble (по func) |
| 103 | `FLW`     | I   | `Fop1 = mem[Rop2 + imm6]` |
| 104 | `FSW`     | I   | `mem[Rop2 + imm6] = Fop1` |
| 105 | `FMOV`    | R   | Пересылка: `Fop1 = Fop2` (func=0), `Rop1 = Fop2` (func=1), `Fop1 = Rop2` (func=2) |
| 106 | `FCLASS`  | R   | Классификация `Fop2` → целое в `Fop1` (0=ноль, 1=∞, 2=NaN, 3=maybe‑NaN, 4=нормальное) |
| 107 | `FSWAP`   | R   | Обмен `Fop1` и `Fop2` |
| 108 | `FZERO`   | R   | `Fop1 = 0.0` |

Поле `func` (младшие 3 трита в R‑типе) уточняет операцию (тип данных, преобразование). В I‑типе (FLW, FSW) младшие 6 трит — непосредственное значение.

## 5. Форматы кодирования

**R‑тип (большинство FPU‑инструкций):**
```
[ opcode+pred (6) | op1 (3) | op2 (3) | op3 (3) | func (3) ]
```
- opcode = 92…108 + pred_index * 28 (предикация).
- op1, op2, op3 — номера FPU‑регистров (0–8).
- func — код функции (например, 0 для tfloat, 1 для tdouble).

**I‑тип (FLW, FSW):**
```
[ opcode+pred (6) | op1_F (3) | op2_R (3) | imm6 (6) ]
```
- op1_F — FPU‑регистр.
- op2_R — регистр основного процессора (RW…R4).
- imm6 — знаковое смещение (–364…+364).

Для `FMOV` с передачей между FPU и основным регистром op2 интерпретируется как номер основного регистра (0–8), а op3 игнорируется.

## 6. Исключения и флаги

Регистр `FSR` (доступен через порт 0x20) содержит флаги:
- Бит 0 (I) — недействительная операция (sqrt отрицательного и т.п.).
- Бит 1 (O) — переполнение.
- Бит 2 (U) — антипереполнение.
- Бит 3 (Z) — деление на ноль.
- Бит 4 (M) — результат maybe‑NaN.

При возникновении исключения соответствующее значение (∞, 0, NaN) записывается в приёмник, и вычисление продолжается. Прерываний нет.

## 7. Интеграция с основным процессором

- Основной процессор декодирует опкоды 92–108 как FPU‑инструкции. Если FPU не реализован (в простой конфигурации), они могут вызывать исключение недопустимой операции.
- VLIW‑процессор может размещать FPU‑инструкции в любом слоте бандла (при условии, что слот позволяет I‑ или R‑формат).
- Обмен данными между регистровыми файлами осуществляется через `FMOV` (func=1 или 2) или через память (сохранение/загрузка).

## 8. Примеры

```asm
; Перевод градусов Цельсия в Фаренгейты: F = C * 1.8 + 32
; R1 = целое значение градусов Цельсия
ITOF FW, R1, 0     ; FW = float(R1) (tfloat)
FLW FX, R2, c1_8   ; загрузить константу 1.8 из памяти
FMUL FY, FW, FX, 0 ; FY = FW * FX
FLW FZ, R2, c32    ; загрузить 32.0
FADD F0, FY, FZ, 0
FTOI R0, F0, 0     ; результат в R0
```

```asm
; Классификация числа и условный переход
FCLASS F1, F2      ; результат в F1 (код: 0..4)
FMOV R0, F1, 2     ; перенести из FPU в основной регистр (func=2)
CMPI R0, 0
JE is_zero
```
