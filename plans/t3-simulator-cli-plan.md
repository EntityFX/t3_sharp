# План CLI-симулятора и ассемблера T3 — v2 (Прототип)

*Примечание: данный план описывает функциональность текущего исследовательского прототипа. Реализация может быть упрощена относительно финальных архитектурных целей.*

## Ассемблер (T3Assembler)

- Два прохода: сбор меток → генерация Word18[]
- Регистры: RW(-4), RX(-3), RY(-2), RZ(-1), R0(0), R1(1), R2(2), R3(3), R4(4)
- Маппинг: тритовое имя → phys индекс = trit + 4
- Encoder: `Word18 Encode(Opcode, pred, op1, op2, op3, imm)` — арифметика без строк
- Поддержка меток, предикатов `(p1)`, директив `.word`
- Форматы вывода: .bin (троичный), .txt (0n/0y), .asm (дизассемблированный)

## Загрузчик (T3ProgramLoader)

- Текстовый формат: `-`, `0`, `+`
- Ninary (0n): 2 трита на символ (WXYZ01234)
- Tryx (0y): 3 трита на символ (N...D, W...V, 5...C)
- Бинарный: упакованные триты

## CLI (T3Simulator.CLI)

- REPL: load, run, step, dump, reset
- Вывод: регистры (RW-R4), PC, SP, Cond, PR
- Память: hexdump
- I/O: stdin/stdout через порты
