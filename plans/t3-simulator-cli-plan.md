# План разработки консольного симулятора и ассемблера T3

## 1. Разработка Ассемблера (T3Assembler)
Цель: Создать инструмент для преобразования текстового кода `.asm` в машинный троичный код.
- **Парсер**:
    - Чтение инструкций, поддержка мнемоник (`ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `NEG`, `MOV`, `LI`, `LIMM`, `LOAD`, `STORE`, `TRITAND`, `TRITOR`, `TRITXOR`, `SHL`, `SHR`, `CMP`, `JMP`, `JE`, `JNE`, `JL`, `JG`, `JM`, `CALL`, `RET`, `PUSH`, `POP`, `IN`, `OUT`, `INI`, `OUTI`, `HALT`).
    - Поддержка именованных меток для переходов.
    - Обработка регистров (A-I) и их отображение на физические регистры.
- **Эмиттер**:
    - Кодирование инструкций в троичные слова (`Word27`/`Word54`).
    - Генерация машинного кода.
- **Экспорт**:
    - Сохранение в трех форматах: текстовом (`-0+`), бинарном (2 бита на трит), Ninary/Tryx.

## 2. Система загрузки данных (T3ProgramLoader)
Цель: Реализовать механизм чтения программ из файлов в различных кодировках.
- **Текстовый формат**: Парсинг символов `-`, `0`, `+`.
- **Бинарный формат**: Чтение байтов (10 -> -1, 00 -> 0, 01 -> 1).
- **Ninary (0n)**: Поддержка алфавита `WXYZ01234` (2 трита на символ).
- **Tryx (0y) [heptavigesimal]**: Поддержка алфавита `NOPQRSTUVWXYZ0123456789ABCD` (3 трита на символ).

## 3. Консольное приложение-симулятор (T3Simulator.CLI)
Цель: Создать интерактивную оболочку для управления процессором.
- **Интерфейс управления (REPL)**:
    - `load <file>`: Загрузка кода из файла.
    - `run`: Выполнение до команды `HALT`.
    - `step`: Пошаговое выполнение одной инструкции.
    - `dump`: Вывод состояния: PC, WP, Cond, значения всех регистров.
- **Интеграция I/O**: Перенаправление вывода процессора (порт 0) в стандартный вывод консоли.
- **Виртуальное устройство**: Реализация загрузчика как устройства ввода.

## 4. Пример: Умножение матриц
Цель: Верификация всей системы на сложном примере.
- **Разработка программы**: Написание кода на ассемблере T3 для умножения матриц.
- **Тестирование**: Полный цикл «Сборка $\rightarrow$ Загрузка $\rightarrow$ Исполнение $\rightarrow$ Проверка результата».
