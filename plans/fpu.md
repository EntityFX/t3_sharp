# Спецификация FPU для процессора T3 (18-тритное слово) — v2

## 1. Регистры FPU

| Регистр | Тритовое значение | Phys индекс |
|---------|-------------------|-------------|
| FW | -4 | 0 |
| FX | -3 | 1 |
| FY | -2 | 2 |
| FZ | -1 | 3 |
| F0 | 0 | 4 |
| F1 | +1 | 5 |
| F2 | +2 | 6 |
| F3 | +3 | 7 |
| F4 | +4 | 8 |

Тритовое значение кодируется в инструкциях (3-тритное поле). Phys индекс = `trit_value + 4`.

## 2. Форматы чисел

- **tfloat** (18 трит): 6 трит порядок + 12 трит мантисса. bias = 182.
- **tdouble** (36 трит): пары регистров (FW,FX), (FY,FZ), (F0,F1), (F2,F3).
- Специальные значения: ноль, ∞, NaN, maybe-NaN.

## 3. Коды операций FPU

| Код | Мнемоника | Тип | Описание |
|-----|-----------|-----|----------|
| 100 | `FADD` | R | `Fop1 = Fop2 + Fop3` |
| 101 | `FSUB` | R | `Fop1 = Fop2 - Fop3` |
| 102 | `FMUL` | R | `Fop1 = Fop2 * Fop3` |
| 103 | `FDIV` | R | `Fop1 = Fop2 / Fop3` |
| 104 | `FSQRT` | R | `Fop1 = sqrt(Fop2)` |
| 105 | `FABS` | R | `Fop1 = abs(Fop2)` |
| 106 | `FNEG` | R | `Fop1 = -Fop2` |
| 107 | `FCMP` | R | `Cond = sign(Fop1 - Fop2)` |
| 108 | `FTOI` | R | `Rop1 = int(Fop2)`, func=разрядность |
| 109 | `ITOF` | R | `Fop1 = float(Rop2)` |
| 110 | `FTOF` | R | tfloat ↔ tdouble |
| 111 | `FLW` | R | `Fop1 = mem[Rop2 + op3]` |
| 112 | `FSW` | R | `mem[Rop2 + op3] = Fop1` |
| 113 | `FMOV` | R | func: 0=F→F, 1=R→F, 2=F→R |
| 114 | `FCLASS` | R | Классификация Fop2 → код в Fop1 |
| 115 | `FSWAP` | R | Обмен Fop1 и Fop2 |
| 116 | `FZERO` | I | `Fop1 = 0.0` |

## 4. Формат кодирования

**R-тип:** `[Pred(3)] [Opcode(6)] [Op1(3)] [Op2(3)] [Op3(3)]`  
**I-тип (FZERO):** `[Pred(3)] [Opcode(6)] [Op1(3)] [Imm(6)]`

Поле `func` передаётся через op3 (младшие 3 трита в R-типе).

## 5. Инструкции в основном ISA

FPU-опкоды 100-116 интегрированы в общий `enum Opcode`. Декодер определяет R/I-тип по опкоду.
