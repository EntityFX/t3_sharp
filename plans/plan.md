# План переписывания T3-процессора

## Регистровая модель

| Регистр | Тритовое значение | Phys индекс | FPU |
|---------|-------------------|-------------|-----|
| RW | -4 | 0 | FW |
| RX | -3 | 1 | FX |
| RY | -2 | 2 | FY |
| RZ | -1 | 3 | FZ |
| R0 | 0 | 4 | F0 |
| R1 | +1 | 5 | F1 |
| R2 | +2 | 6 | F2 |
| R3 | +3 | 7 | F3 |
| R4 | +4 | 8 | F4 |

- Тритовое значение кодируется в инструкциях (3 трита, диапазон -13..+13)
- Phys индекс = `trit_value + 4`
- Всего 9 регистров, 9 FPU-регистров

## Формат инструкции (18 трит)

```
[Pred (3)] [Opcode (6)] [Args (9)]
```

- Pred: 3 трита, p0=безусловно, p1-p3 — предикатные флаги
- Opcode: 6 трит, 3^6=729 возможных опкодов
- Args: 9 трит, R-тип: [Op1(3)] [Op2(3)] [Op3(3)], I-тип: [Op1(3)] [Imm(6)]

## Этап 1: Word18 на int ✅

- Контейнер: `readonly struct Word18` с полем `int _value`
- 3^18 = 387,420,489 < 2^31, помещается в 32-битный int
- Операции: арифметика, сдвиги, тритовые операции — без строк
- `ToTritString()` — для отладки, не в основном коде

## Этап 2: Instruction Encoder/Decoder ✅

- **Encoder**: `static Word18 Encode(Opcode op, int pred, int op1, int op2, int op3, int imm)`
- **Decoder**: `static DecodedInstruction Decode(Word18 word)`
- Без строковых операций — чистая арифметика деления/умножения на степени 3

## Этап 3: ProcessorBase + T3InOrderProcessor ✅

- Регистры: `Word18[9]` — простой массив
- FPU: `T3Float[9]`
- Память: `Word18[]` без MMIO
- ExecuteInstruction: switch по Opcode

## Этап 4: Assembler + Disassembler ✅

- Ассемблер: текст → Word18[]
- Маппинг: только RW-R4 (тритовые имена)
- Дизассемблер: Word18[] → текст (RW-R4)

## Этап 5: T3Compiler ✅

- T-lang → Word18[] напрямую (без текстового ассемблера)
- AllocR: свободные регистры 0-8
- _nextAddr = 200+
