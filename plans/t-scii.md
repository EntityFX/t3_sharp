# Полная спецификация кодировки T‑SCII

## 1. Введение
T‑SCII (Ternary Standard Code for Information Interchange) — стандартная 6‑тритная кодовая таблица языка T, предназначенная для представления текста в сбалансированной троичной системе. Каждый символ занимает ровно один трайт (`tryte`, диапазон значений –364…+364).  
Кодировка полностью совместима с CP‑1251 для кодов 0–255 (включая ASCII), располагая их в положительной области значений трайта (0…255). Оставшиеся 473 позиции отведены под дополнительные символы (греческий алфавит, расширенная латиница, псевдографика, математические и технические знаки).

## 2. Принцип кодирования
- **Значение трайта** `V` = –364 … +364.
- **Беззнаковый номер** `U = V + 364` (0 … 728).
- **Троичное представление** получается разложением `U` в 6‑разрядную систему с основанием 3:
  - Цифра `0` → трит `-`
  - Цифра `1` → трит `0`
  - Цифра `2` → трит `+`
- Триты записываются от старшего разряда к младшему (слева направо).

**Пример:** символ `'A'` (код CP‑1251 = 65).  
`V = 65`, `U = 65 + 364 = 429`.  
429 = 1·3⁵ + 2·3⁴ + 2·3³ + 1·3² + 2·3¹ + 0·3⁰ → цифры: 1,2,2,1,2,0 → триты: `0 + + 0 + -`.  
Троичный трайт: `0 + - + + -` (после перестановки, потому что младшая цифра даёт младший трит? Уточним: при разложении первая полученная цифра — старший разряд, поэтому последовательность: 0 (старший), +, +, 0, +, - (младший). Так и записываем: `0 + + 0 + -`.

## 3. Диапазоны кодов T‑SCII

| Значение V | Беззнаковый U | Назначение |
|------------|---------------|------------|
| –364 … –1  | 0 … 363       | Дополнительные символы (греческий, расширенная латиница, стрелки, псевдографика, некоторые математические знаки) |
| **0 … 255** | **364 … 619** | **Стандартная часть CP‑1251 (ASCII + кириллица + спецсимволы)** |
| 256 … 364  | 620 … 728     | Математические и технические символы, специальные глифы |

## 6. 9‑ричное и 27‑ричное представления

### 6.1. 9‑ричное (пары тритов)
Каждые два трита кодируются одним символом:

| Старший | Младший | Пара | Символ |
|---------|---------|------|--------|
| `-`     | `-`     | – –  | `W`    |
| `-`     | `0`     | – 0  | `X`    |
| `-`     | `+`     | – +  | `Y`    |
| `0`     | `-`     | 0 –  | `Z`    |
| `0`     | `0`     | 0 0  | `0`    |
| `0`     | `+`     | 0 +  | `1`    |
| `+`     | `-`     | + –  | `2`    |
| `+`     | `0`     | + 0  | `3`    |
| `+`     | `+`     | + +  | `4`    |

Трайт записывается тремя символами в порядке: старшая пара, средняя, младшая.

**Пример:** `'A'` (0 + - + + -) → пары: `0+` (1), `-+` (Y), `+-` (2) → `0n1Y2`.
