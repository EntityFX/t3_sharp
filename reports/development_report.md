# Отчёт по разработке системы троичного процессора T3

Данный документ представляет собой полный технический отчёт о текущем состоянии разработки симулятора троичного процессора T3, включая архитектурные решения, систему команд, инструменты ассемблирования и стратегию верификации.

---

## 1. Фундамент: Троичные типы данных
В основе системы лежит **сбалансированная троичная система счисления** (значения: $-1, 0, +1$), что обеспечивает естественное представление отрицательных чисел и высокую эффективность некоторых арифметических операций.

- **Базовые единицы**:
    - `Trit`: минимальная единица ($-1, 0, +1$).
    - `Tryte`: группа из 6 тритов (диапазон $\pm 364$).
- **Разрядность слов**:
    - **T3-27**: 27 тритов ($\approx \pm 3.8 \cdot 10^{12}$).
    - **T3-54**: 54 трита ($\approx \pm 2.9 \cdot 10^{25}$).
- **Реализация в C#**: 
    - Для поддержки T3-54 используется тип `Int128`, так как $3^{54} > 2^{64}$ (значение превышает возможности `long`). 
    - Реализован класс `BalancedTernary` для конвертации между десятичными числами и троичными строками/массивами.

## 2. Архитектура процессоров
Реализовано две микроархитектуры, поддерживающие единую систему команд (ISA).

### 2.1. In-Order (Последовательный)
- **Конфигурации**: T3-27 и T3-54.
- **Принцип**: Последовательное выполнение одной инструкции за такт (с учетом задержек АЛУ).
- **Особенности**: Отсутствие конвейеризации, простая эмуляция предикации.

### 2.2. VLIW (Very Long Instruction Word)
- **Конфигурация**: Только T3-54.
- **Параллелизм**: Выполнение до 3-х инструкций одновременно (в одном бандле).
- **Конфликт-менеджмент**: 
    - Запрет одновременной записи в один регистр.
    - Приоритет доступа к памяти: Слот $0 > 1 > 2$.
- **Продвинутые функции**:
    - **Предикация**: Каждая инструкция в бандле может быть привязана к флагу предиката в регистре `PR`.
    - **Спекуляция**: Инструкции `SPEK`, `COMMIT` и `ROLLBACK` позволяют выполнять блок команд в «теневом» состоянии с возможностью полного отката изменений.
    - **SIMD**: Векторные операции (например, `VADD3`, `VDOT3`), обрабатывающие слово как три независимых сегмента.

### 2.3. Общие черты
- **Регистровая модель**: 27 общих регистров.
- **Регистровое окно**: Динамический сдвиг окна (`WP`) при вызовах `CALL`/`RET`, что минимизирует копирование параметров между функциями.
- **Память**: Пословная адресация, стек растёт вниз.

## 3. Система команд (ISA)
Процессор T3 обладает богатым набором инструкций, разделенным на функциональные группы:

| Группа | Инструкции | Описание |
| :--- | :--- | :--- |
| **Арифметика** | `ADD`, `SUB`, `MUL`, `DIV`, `MOD`, `NEG` | Базовая троичная арифметика |
| **Логика** | `TRITAND`, `TRITOR`, `TRITXOR` | Потритовые операции (min, max, sum mod 3) |
| **Сдвиги** | `SHL`, `SHR` | Умножение/деление на степени 3 |
| **Память** | `LOAD`, `STORE`, `LI`, `LIMM` | Работа с ОЗУ и непосредственные значения |
| **Управление** | `JMP`, `JE`, `JNE`, `JL`, `JG`, `JM` | Переходы на основе флага `Cond` |
| **Подпрограммы**| `CALL`, `RET` | Управление стеком и сдвиг окна регистров |
| **Стек** | `PUSH`, `POP` | Сохранение/восстановление данных |
| **VLIW/SIMD** | `SPEK`, `COMMIT`, `VADD3`, `VCMP` и др. | Спекуляция и векторные вычисления |
| **Ввод-Вывод** | `IN`, `OUT`, `INI`, `OUTI` | Работа с портами устройств (stdout, stdin и др.) |

## 4. Система ассемблирования
Разработан модульный ассемблер, позволяющий преобразовывать высокоуровневый код в машинные слова.

- **Иерархия**: `T3AssemblerBase` $\rightarrow$ (`T3InOrderAssembler`, `T3VliwAssembler`).
- **Функционал**:
    - Поддержка меток и автоматический расчет адресов.
    - Разрешение имен регистров (`A`-`I`).
    - Поддержка директивы `.word` для вставки данных.
- **VLIW-специфика**: Введен синтаксис бандлов: `{ inst1 | inst2 | inst3 }`. Если инструкций меньше трёх, остальные слоты автоматически заполняются `NOP`.
- **Форматы вывода**: Текст, Binary (сжатый), Ninary, Tryx.

## 5. Верификация и тестирование
Система тестирования построена на базе **MSTest** и разделена по уровням:

1. **Unit-тесты (`TritTypes.Tests`)**: Проверка корректности троичной арифметики, конвертации `long` $\leftrightarrow$ `Int128` $\leftrightarrow$ `Trit[]`.
2. **Инструкционные тесты**: Изолированная проверка каждой команды ISA на корректность изменения состояния регистров и памяти.
3. **Архитектурные тесты**:
    - Тестирование сдвига регистрового окна при вложенных вызовах.
    - Проверка работы спекулятивного выполнения (COMMIT/ROLLBACK).
    - Верификация SIMD-операций.
4. **Интеграционные тесты**:
    - Запуск сложных алгоритмов: вычисление факториала, перемножение матриц.
    - Проверка работы циклов и ветвлений.

## Итог
На текущий момент создана полноценная программная среда для разработки под T3. Процессоры поддерживают как простую последовательную логику, так и сложные VLIW-механизмы. Ассемблер обеспечивает удобный переход от мнемоник к машинному коду, а система тестов гарантирует корректность реализации спецификации.
